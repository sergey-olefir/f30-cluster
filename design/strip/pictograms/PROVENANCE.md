# Provenance and licence: design/strip/pictograms/

Package P, 2026-11-16. Applies to every file in this folder and its subfolders.

## What is here, and where it came from

| Path | What | Made from | Licence |
|---|---|---|---|
| `pictograms.js` | The pictograms as distance functions (the `shared/icons.js` contract) and as SVG | Drawn by package P from primitives (lines, arcs, discs, rounded boxes). The shapes follow the tell-tales that ISO 2575 and UN R121 Table 1 standardise. **Nothing was traced, sampled or measured from BMW artwork, from a photo of it, or from the car snapshot.** | MIT (the repository's `LICENSE`) |
| `svg/*.svg` | One vector per pictogram, in `currentColor` | Generated from `pictograms.js` by `tools/strip/P/bake_pictograms.js` | MIT |
| `baked/*.png`, `baked/index.json` | White ink plus alpha, 8-bit grey+alpha, drawn by `shared/icons.js` `paintIcon()` at the sizes in `index.json` | Generated from `pictograms.js` by the same tool | MIT |
| `sheet.png` | A review sheet of every pictogram at every size | Generated by the same tool | MIT |
| `cc_catalogue.json` | Check-control id → meaning | Public sources only: BMW service bulletins published on nhtsa.gov and one community list. Each entry names its sources. Meanings are paraphrased in our own words. No BMW message text, and nothing from the car's snapshot except field and type **names** from its interface catalogue (already cited in `docs/G20-DESIGN-SPEC.md`). | MIT for our compilation; ids and meanings are facts |
| `signs/proportions.json` | Speed-limit and no-overtaking sign ratios for three sets: stock, VzKat, ours | **stock**: numbers from `docs/G20-DESIGN-SPEC.md` §4, measured on the owner's photos (numbers only, no pixels). **vzkat**: numbers measured by package P on the Wikimedia Commons SVGs of German Zeichen 274-50 and 276. Those files are public domain (an official work under § 5 UrhG, per their Commons pages); only dimensions were read and no path was copied. **ours**: measured from our own `apps/f30_cluster/hud/scene/sign_*.json`. | MIT |
| `signs/*.svg` | Each set drawn at the stock size | Our own drawing by `tools/strip/P/signs.js`: circles, our own rounded-box cars, and a figure set in a generic sans-serif (no font file embedded) | MIT |

## What is NOT here, by rule

- No BMW font file, glyph outline or bitmap.
- No pixel from `reference/` (the owner's photos) or `reference/car/` (the snapshot). Not even a crop, a
  threshold or a mask derived from one.
- No BMW check-control text, Ukrainian or English.
- The car's own symbol bitmaps (`KISymbolStruct.symbolData`, which the head unit can send with a message) are BMW
  artwork. The interface catalogue names them, but they are never to be saved, baked or committed. See
  `cc_catalogue.json` `_symbolId`.

## Re-making the files

```sh
node tools/strip/P/bake_pictograms.js            # svg/, baked/, sheet.png
node tools/strip/P/bake_pictograms.js --sizes s.json   # other sizes: { "markers": [[w,h],...], "symbols": [[w,h],...] }
node tools/strip/P/signs.js [--stock zl.json]    # signs/; zl.json = { outer, inner, figure, pairWidth } from package ZL
```
